# Convex Backend

This directory holds the Convex backend for World of Floorcraft. It is being
introduced by the Convex migration — see
`docs/superpowers/plans/2026-05-22-convex-migration.md` and
`docs/superpowers/specs/2026-05-22-convex-migration-design.md`.

## Current state (Task 1: foundation)

Task 1 wires up tooling, the Clerk-backed client provider, auth config, and the
test harness. Schema and domain functions land in later tasks.

| File | Purpose |
| --- | --- |
| `auth.config.ts` | Tells Convex to trust Clerk-issued JWTs (`applicationID: "convex"`). |
| `test.setup.ts` | Exports `modules` (a `import.meta.glob` of Convex function files) for `convex-test`. |
| `foundation.test.ts` | Smoke test, **skipped** until Task 2 adds `schema.ts`. |

Not yet present (added by later tasks):

- `schema.ts` — full table set (Task 2).
- `lib/*` — shared helpers: auth, errors, money, time, pagination, permissions (Task 2).
- `_generated/*` — generated by `npx convex dev` once a schema exists.
- Domain modules (`syllabus/`, `social/`, `competitions/`, ...) — Tasks 3–11.

## Environment variables

| Variable | Used by | Notes |
| --- | --- | --- |
| `NEXT_PUBLIC_CONVEX_URL` | `src/shared/components/convex-client-provider.tsx` | Deployment URL. Written to `.env.local` by `npx convex dev`. |
| `CLERK_JWT_ISSUER_DOMAIN` | `auth.config.ts` | Clerk Frontend API URL. From https://dashboard.clerk.com/apps/setup/convex |

See `.env.example` for the documented entries.

## Provisioning

Once `schema.ts` exists (Task 2), provision a local anonymous deployment,
generate `_generated/`, and validate functions and schema in one shot:

```bash
CONVEX_AGENT_MODE=anonymous npx convex dev --once
```

This step is intentionally deferred in Task 1: `convex dev` has nothing to
generate types from until the schema exists.

## Tests

Convex tests run under the `convex` vitest project (`edge-runtime` environment),
configured in `vitest.config.ts`. Run just the Convex foundation test with:

```bash
pnpm test -- convex/foundation.test.ts
```

## Convex AI guidance

Project-local Convex skills already live under `.agents/skills/convex*`
(`convex`, `convex-quickstart`, `convex-setup-auth`, `convex-migration-helper`,
`convex-performance-audit`, `convex-create-component`). They are the installed
Convex guidance — consult them when writing Convex code. Refresh them with
`npx convex ai-files install` if they look stale; that command is not run as
part of Task 1 because the guidance is already present.
